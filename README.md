# VikBox — Mi sitio personal

Sitio web responsive de una sola página para reunir el contenido de VikBox, las redes sociales y proyectos técnicos.

## Cómo abrirlo en la Mac

1. Descomprime `vikbox-portfolio.zip`.
2. Abre la carpeta `vikbox-portfolio`.
3. Haz doble clic en `index.html`: se abre en Safari o el navegador que tengas configurado.

No necesitas instalar programas, ejecutar servidores ni contratar alojamiento para verlo en tu computadora. Los enlaces externos requieren conexión a internet.

## Portafolio

Los seis proyectos listados enlazan a repositorios públicos de GitHub: `crudweb`, `bolsa-tiempo-real`, `costeo-recetas`, `crud_Mongo`, `Hospital` y `RedLink`. DIMENSION X está etiquetado **En desarrollo**, sin fingir que existe una demo pública.

## Cómo editar los textos y enlaces

Abre `index.html` con un editor de texto y usa Buscar (`Cmd + F`) para localizar `victorjr_x`, `v1ctorjr_x`, `VictorAriasAM` o el título del proyecto. Guarda el archivo y vuelve a cargar la pestaña del navegador.

Las variables de colores están al principio del archivo, en la regla `:root`.

## Publicarlo gratis con GitHub Pages

1. Entra a GitHub con tu cuenta y crea un repositorio público nuevo llamado `vikbox`.
2. Sube el contenido **de esta carpeta** (`index.html` y `favicon.svg`) a la raíz del repositorio.
3. En el repositorio, entra a **Settings > Pages**.
4. En **Build and deployment**, elige **Deploy from a branch** y selecciona **main** y **/(root)**. Guarda.
5. GitHub te mostrará la dirección publicada, normalmente `https://VictorAriasAM.github.io/vikbox/` (la dirección será válida únicamente cuando tú lo publiques).

La página también funciona en otros servicios de alojamiento estático.

## Notas

- El sitio no usa frameworks ni librerías externas.
- Responsive para celular y desktop.
- Filtro funcional en el portafolio y menú móvil.
- Las ilustraciones de las tarjetas son decorativas, no capturas reales de tus aplicaciones.
- No se incluyen materiales privados ni capturas del trabajo de QA con clientes.
