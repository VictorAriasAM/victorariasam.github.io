# VikBox 2.0 · Sitio personal

Sitio estático para GitHub Pages de Víctor Arias: contenido tech, TikTok/Instagram, seis repositorios y el prototipo **DIMENSION X**.

## Contenido
- `index.html`: diseño adaptable y navegación, tarjetas de redes sociales, filtros de proyectos y galería ampliable.
- `favicon.svg`: ícono VikBox.
- `assets/`: fotografías reales y un breve video de DIMENSION X (rotados a horizontal para mostrarse correctamente).

## Verlo en tu Mac
Abre `index.html` en Safari o Chrome. No necesita instalar dependencias ni compilar.

## Publicar la actualización en GitHub Pages
1. Abre `https://github.com/VictorAriasAM/victorariasam.github.io`.
2. En el repositorio, abre **Add file → Upload files** (en algunas interfaces está en el botón `+`).
3. Arrastra **`index.html`, `favicon.svg` y toda la carpeta `assets`** desde la carpeta descomprimida `vikbox-2`. No subas el ZIP ni una carpeta extra `vikbox-2`.
4. Confirma que `index.html` quede en la raíz y `assets` quede al lado (no adentro de otra carpeta). GitHub debería mostrar los archivos agregados/reemplazados.
5. Pulsa **Commit changes**, directamente a `main`.
6. La página se actualizará automáticamente en `https://victorariasam.github.io/` una vez termine el despliegue.

No es necesario modificar Settings → Pages si ya está configurado desde `main` / `(root)`.

## Notas
- Los enlaces de los videos en las tarjetas sociales apuntan a perfiles, no a una publicación concreta: reemplázalos por enlaces de videos individuales cuando los tengas.
- DIMENSION X se presenta como **prototipo en desarrollo**; no se afirma que tenga todas las mecánicas terminadas.
- No se incluye enlace a repositorio de DIMENSION X porque no se proporcionó uno público.
- Las fotografías son originales del creador, sin generación artificial.
